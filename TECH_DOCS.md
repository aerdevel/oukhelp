# Техническая документация OUK Help Bot

## Потоки данных

- Пользователь проходит FSM-сценарий в `handlers/*`.
- Данные нормализуются и валидируются в `utils/validators.py`.
- Черновики и статусы модерации сохраняются в `data/*.json` через `services/*_store.py`.
- Итоговые и промежуточные данные пишутся в Excel через `services/excel_registry.py`.
- Ответственные сотрудники получают уведомления через `services/notifier.py`.

## Регистрация

Основной файл: `handlers/registration.py`.

Этапы:
- Сбор ФИО -> телефона -> роли -> кафедры/специальности -> группы/курса.
- Финальное подтверждение вызывает `add_pending_registration`.
- Для каждой повторной отправки выставляется `submit_attempt` (начиная с 1).
- Перед отправкой номера выполняется проверка владельца:
  - тот же `tg_user_id` — разрешено;
  - другой пользователь — отклонение с подсказкой.
- После `upsert_registration_account_record` в уведомление ответственным уходит:
  - номер попытки;
  - признак, была ли запись в Excel ранее (`✅/❌`);
  - признак успешной записи в Excel (`✅/❌`).

## Перечень документов

Основной файл: `handlers/documents.py`.

Этапы:
- Сбор недостающих анкеты/телефона/источника.
- Выбор факультета и специальности поступления.
- Последовательная загрузка документов.
- Подтверждение согласия на обработку ПД.
- Сохранение пакета в pending + запись в Excel (status=pending) + отправка в чат модерации.

Особенности:
- Для повторных отправок пакета ведется `submit_attempt`.
- В карточке пакета в чате модерации показывается статус Excel (`✅/❌`).
- При ошибке отправки в чат модерации бот делает безопасный fallback-алерт админу.

## Excel слой

Файл: `services/excel_registry.py`.

`upsert_*` теперь возвращают структурный результат:
- `ok`: запись выполнена;
- `path`: куда сохранено;
- `is_fallback`: использован fallback-файл;
- `was_existing`: строка уже была до upsert.

Это позволяет явно подтверждать факт дублирования/обновления данных в служебных уведомлениях.

## Управление доступом

Файл: `services/access_control.py` + UI в `handlers/registration.py`.

Кнопки админа:
- `Уведомления` (`can_notify`) — получать новые входящие заявки.
- `Модерация` (`can_review`) — открывать и обрабатывать заявки/пакеты.
- `Админ права` (`is_admin`) — полный доступ к панели прав.
- `Назначить специальности` (`specialties`) — ограничение области модерации.
