# OUK Help Bot

Telegram-бот для абитуриентов и студентов ОУК: два трека (университет / колледж), регистрация, пакет документов, модерация, права ответственных, психологическая поддержка и служебные рассылки.

## Запуск

1. Скопируйте настройки окружения (см. `core/config.py` и переменные вроде `BOT_TOKEN`, `ADMIN_ID`, пути Excel).
2. Установите зависимости: `pip install -r requirements.txt`
3. Запуск polling: `python main.py`

Подробнее по архитектуре и потокам данных см. [TECH_DOCS.md](TECH_DOCS.md). Для новичков в кодовой базе — [ПОЯСНЯЛКА_ДЛЯ_НОВИЧКОВ.md](ПОЯСНЯЛКА_ДЛЯ_НОВИЧКОВ.md).
